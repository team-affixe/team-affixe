## 🧩 Aktuelles Projekt: AI Agent User Interface – powered by Ollama

Ein modernes, modulares Interface für eine **lokal laufende AI‑Instanz** auf Basis von **Ollama**.  
Ziel des Projekts ist es, eine Oberfläche zu schaffen, die sich **wie ein echter digitaler Assistent** anfühlt: klar, reaktiv, visuell ansprechend und flexibel erweiterbar.

## 🎯 Fokus des Projekts

- **AI‑Interaktionen** werden verständlich und transparent dargestellt  
- **Agenten‑Zustände** werden visuell aufbereitet  
- **Task‑Flows** sind klar strukturiert und nachvollziehbar  
- **Live‑Feedback** zeigt jederzeit, was der Agent gerade tut  
- **Modulare Komponenten** ermöglichen flexible Erweiterungen  
- **Direkte Anbindung an Ollama** für schnelle, lokale und private AI‑Interaktionen

Dieses Interface soll langfristig:
